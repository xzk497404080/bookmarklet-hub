它是什么，以及边界在哪

书签工具就是一段存在书签栏里的 JavaScript，不是扩展，也不装东西

代码全可见
没有压缩混淆的黑箱，装之前可以先读一遍，觉得不对就不装
数据不出本机
不经过任何服务器，cookie 只在你自己浏览器里用，作者看不到你的数据
随时能删
删掉书签就什么都没了，不留后台进程、不改站点配置
怎么装：打开任意工具的安装页，按住彩色按钮拖到书签栏（⌘⇧B / Ctrl+Shift+B 调出）。
装不上：点「复制代码，手动新建书签」，把内容粘到书签的地址栏里。手机端只能用这个办法。
有问题：去 GitHub 提需求或报 Bug，说清楚你在哪个站、点了什么、期待什么。按用途分组时，一个工具可能出现在多个分组里。

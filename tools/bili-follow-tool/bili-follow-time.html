查你是什么时候关注某个 UP 的

B 站官方不给看关注时间。这个书签小工具会读完你关注列表里的真实时间戳，按年分布、按时间排序，还能导出 CSV。

安装

装一次，以后在 B 站任何页面点一下就能用
B站关注时间 ↑ 按住拖到书签栏

按住左边这个粉色按钮，拖到浏览器地址栏下方的书签栏上松手，书签名字就是「B站关注时间」。看不到书签栏？按 ⌘⇧B（Windows 为 Ctrl+Shift+B）调出来。

使用

三步，十秒钟
  1. 在浏览器里登录 bilibili.com（工具要靠你的登录态读关注列表）。
  2. 想查某个 UP？直接打开他的主页，点书签栏里的「B站关注时间」——工具会识别当前页面的 UID，直接把他的关注时间顶到最上面。想看全部关注，就在任意 B 站页面点。
  3. 等几秒，全屏面板列出所有关注的人和关注时间。搜人名、点年份柱子筛选、导出 CSV、按 Esc 关掉。

能做什么

数据来自 B 站真实接口，不是估算
●按关注时间正序 / 倒序排列
●年份柱状图，点一下只看那年
●按昵称或 UID 搜索
●筛选互关 / 单向关注
●标注特别关注
●一键导出 CSV（Excel 直开不乱码）

安全

为什么敢让你把登录态交给它
因为根本没有「交给」这一步。工具是一段跑在 bilibili.com 页面里的脚本，请求由你自己的浏览器发出、cookie 由浏览器自动附加，全程不出本机、不经任何服务器。整个工具没有任何后端、没有上报、没有第三方域名，你可以把代码展开逐行审。

不放心的话，用完后在 B 站「设置 → 隐私」里退出登录，或直接删掉这个书签，不会留下任何痕迹（工具本身不写 localStorage）。

常见问题

几个会让人误判的坑
为什么显示的时间比我印象中晚？

B 站的 mtime 在互相关注时会刷新。如果你和对方是互关，显示的是「成为互粉」的时间，不是你第一次点关注的时间。单向关注（列表里没有「互关」标签）才是准确的首次关注时间。

取关过又关注回来，会怎样？

B 站不保存关注历史，只有当前关系的最后时间戳。取关再关注会把时间覆盖成新的，旧记录无法找回。

提示「关注列表不可见」？

你的隐私设置里关掉了公开关注列表，接口返回 22115。去 B 站「设置 → 隐私设置 → 公开我的关注列表」打开即可。

能查别人的关注时间吗？

不能。别人的关注列表只返回前 100 条，而且没有意义——那是「他关注别人的时间」，不是「你关注他的时间」。查「你关注某人」的时间，只能查你自己账号的数据。

关注几千个人会不会很慢 / 被封？

每页 50 条，页间间隔 140ms。3000 个关注约 60 页，十几秒跑完。这是正常的人类操作频率，实测无风控。如果中途报错，重新点一次书签即可。

它用了什么接口

想自己写脚本的话，抄这两行就够
GET /x/web-interface/nav
  → data.mid / data.uname / data.isLogin

GET /x/relation/followings?vmid={mid}&pn={页码}&ps=50&order=desc
  → data.total / data.list[].{mid,uname,face,mtime,attribute,special}

mtime = 关注时间（秒级时间戳）
attribute: 0 未关注 / 2 单向关注 / 6 互相关注 / 128 已拉黑
不需要 wbi 签名，不需要任何后端

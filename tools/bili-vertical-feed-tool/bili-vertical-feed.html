B 站竖滑信息流

把 B 站首页推荐改成抖音推荐页那种沉浸式样式：深色底、一条一屏、上下滑动自动切下一条，默认静音连播。

B 站竖滑信息流 ↑ 按住拖到书签栏

按住左边这个粉色按钮，拖到浏览器地址栏下方的书签栏上松手。
看不到书签栏？按 ⌘⇧B（Windows 为 Ctrl+Shift+B）调出来。代码大小约 。

怎么用

  1. 在浏览器里登录 B 站，打开 www.bilibili.com 首页。
  2. 点一下书签栏里的「B 站竖滑信息流」，等它拉取第一屏推荐（几秒钟）。
  3. 滚轮 / ↓ ↑切上一条下一条；空格播放暂停；M 静音开关。
  4. 默认静音自动连播：当前视频播完自动滑到下一条；底部有进度条、倍速、音量、清屏、全屏。
  5. 顶部输入框搜 B 站视频，回车后搜索结果直接进入当前信息流播放；左侧「搜索历史」点一下展开最近 5 条、再点展开全部 B 站历史、第三次折叠，点词条直接搜。
  6. 左侧 推荐 / 热门 / 已关注投稿 分别是三个独立数据源：首页推荐流、热门榜、动态里的关注视频投稿；顶部 换一批 会重新拉首页推荐并立刻切到新刷出来的第一条。
  7. 底部控制条（进度条后面）可切清晰度、倍速与音量；清晰度按当前视频和账号实际支持列出 360P / 480P / 720P / 1080P / 1080P+ / 4K，顶部可关自动连播。
  8. 右侧点赞会同步到 B 站账号；收藏点开自己的收藏夹列表，勾选后确定即真实收藏；评论跳到该视频最新一条评论（#reply 锚点）。
  9. 再点一次书签、按 Esc、或点右上角 ✕ 关闭，原 B 站页面原封不动。

它怎么工作

取数
首页推荐 feed/rcmd、热门 popular、关注动态 feed/all?type=video、搜索 search/type，四套独立列表
搜索历史
按 B 站自己的存储协议读搜索历史（最多 20 条），折叠 / 最近 5 条 / 全部三态
播放
官方 playurl 接口拿直链，默认 720P；DASH 多档位本地切换并同步独立音轨，只预加载当前和下一条
布局
深色全屏、模糊背景、右侧操作栏、底部信息 + 控制条
切换
滚轮 / 方向键 / 视频播完自动切
互动
点赞 / 收藏调用 B 站官方写接口，评论跳 #reply 锚点，分享复制 bvid 链接
存储
不写 localStorage，刷新或关闭即清空
限制与已知坑
浏览器自动播放策略要求先静音，所以打开时默认静音（喇叭是静音图标），点底部喇叭、拖音量条或按 M 开声；音量条可随时调节。
清晰度列表取自 playurl(fnval=16) 实际返回的档位，只有你的账号和该视频支持的才会出现；1080P 以上走 DASH 视频流 + 独立音轨，切换时只换当前视频，其他已加载的不重下。
部分大会员或地区受限视频，官方 playurl 可能返回不了直链；遇到这种情况界面会提示，点标题去 B 站原页面看。
点赞 / 收藏是真实写入：点赞用 archive/like，收藏用 fav/resource/deal，都需要浏览器里的 bili_jct cookie。没读到 cookie 会明确提示，不会静默失败。收藏默认读取你自己的收藏夹列表，勾选后确定才会提交；取消收藏也是真实删除。
评论按钮取的是 reply/main?mode=3 返回的最新一条评论的 rpid，新标签打开 ...#reply<rpid> 让 B 站自己定位；如果视频没有评论会提示。
搜索与关注动态里的条目没有 cid，会先调 view 补出 cid 和真实播放数据再起播，所以切换时可能多等半秒。
搜索历史只是读取 B 站已经存好的搜索词（它自己限 20 条），不写回 B 站；本工具自己搜过的词只保存在当前页面内存里，关闭即清空。
它只是盖在 B 站页面上的一层全屏 iframe，没有替换原页面；关掉后原来的首页还在，B 站自己的推荐算法没有被改动。
安全：纯前端，没有后端、没有服务器、没有任何上报。它用你自己的登录态调用 B 站官方推荐与播放接口， 数据只在你浏览器本机处理，不上传。整段代码约 81.2 KB，装好后可在书签上右键「编辑」逐行查看。

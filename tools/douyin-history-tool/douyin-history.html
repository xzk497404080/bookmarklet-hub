抖音观看历史分析

在抖音「观看历史」页点一下，把最近刷过的视频全部抓下来 —— 先给你算一卦人格称号，再说清楚你到底在刷什么、刷了多久。

抖音观看历史分析 ↑ 按住拖到书签栏

按住左边这个红色按钮，拖到浏览器地址栏下方的书签栏上松手。
看不到书签栏？按 ⌘⇧B（Windows 为 Ctrl+Shift+B）调出来。代码大小约 。

怎么用

  1. 在浏览器里登录抖音，打开 www.douyin.com/user/self?showTab=record（就是「观看历史」这一栏）。
  2. 点一下书签栏里的「抖音观看历史分析」。
  3. 它会自己一路往下滚，滚到滚不动为止（滚到底、连续几次都不再出新内容才停），然后再出报告。
  4. 记录多的时候要等十几秒到一分钟，进度条下面会实时告诉你抓到几条、现在是在往下滚还是在等加载。
  5. 想更新数据就再点一次，或者点面板里的「重新抓取」。再点书签会关掉面板（也会立刻停止滚动）。
  6. 需要存档点「导出 CSV」，Excel 直接打开不乱码。

它分析什么

人格画像
老色批 / 科技范 / 缅A老铁…按你刷最多的那类发称号
真爱与手滑
刷得最多 ≠ 停得最久，把这两件事拆开对比
时间节律
24 小时分布、星期分布、连续刷了多久
内容画像
时长偏好、追爆款还是挖冷门、追新还是考古
榜单
最常看的作者、话题、BGM
节奏
看完才走 / 3 秒划走的比例

称号怎么来的：按标题、#话题、作者昵称、合集名、BGM 里的关键词把每条记录归到 28 个类别之一 （出现「涨停」「缅A」算财经，出现「短剧」「大结局」算剧情），再按条数排出主场、按平均停留排出真爱与手滑。 关键词没覆盖到的会归入「其他杂项」，并在面板里告诉你占比 —— 它不猜你心里想什么，只看你把时间花在哪儿。

关键的一点：抖音不返回「每条到底看了几秒」，工具用相邻两条记录的时间差倒推停留时长，再拿视频片长封顶。 所以「估算实际观看」和按类别算的停留都是估算值，看相对大小，别当精确账。片长总和则是准确的。

一个必须说清楚的限制
抖音网页版的观看历史是一段一段往下加载的，能翻多深取决于你在那一页滚多久、滚多彻底 —— 滚两屏就停手只能看到最近两三天，一路滚到不动能看到一周左右。所以这个工具的做法是先滚到底再分析： 回顶部、逐屏往下、到底后反复等加载，连续几次都不出新内容才停。
如果某次确实没滚到底（比如网慢、页面还在吐），面板顶部会明说，并给你一个「再往前抓」的按钮， 从当前位置接着往下挖，不用从头重扫。
更早的记录站点自己就不给了，所以还有第二层兜底：本地累积 —— 每次点一下，就把这次能看到的记录 并进浏览器本机的存档、按 ID 去重，一直叠加。用上几周，你就有了一份跨越几个月的个人观看档案。
数据存在你自己浏览器的 localStorage 里，换浏览器或清缓存就没了 —— 重要的记得先导 CSV。
安全：纯前端，没有后端、没有服务器、没有任何上报。它读的是你自己浏览器里已经渲染好的页面， 不调用抖音的任何私有接口，也不需要你的 cookie 或密码。整段代码约 130.7 KB， 装好后可以在书签上右键「编辑」逐行看。

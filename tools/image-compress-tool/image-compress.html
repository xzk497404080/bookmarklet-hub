图片压缩

在任意网页点一下书签，把本地图片拖进来。选格式、拖质量、限尺寸，实时看每张压完多大，逐张下载或打包 ZIP。全程在你浏览器里跑，不上传、不保存。

图片压缩 ↑ 按住拖到书签栏

按住蓝色按钮拖到浏览器书签栏松手。看不到书签栏按 ⌘⇧B（Windows Ctrl+Shift+B）。
代码约 ，全部可读，右键书签「编辑」能逐行看。

1怎么用

  1. 打开任意网页（不需要登录、不挑站点），点一下书签，压缩面板弹出来。
  2. 把图片拖进面板中间的虚线框，或点虚线框一次选多张。支持 JPG / PNG / WebP / GIF。
  3. 顶部调参数：输出格式（保持原格式 / JPG / PNG / WebP）、压缩质量（10%–100%）、尺寸（保持 / 缩小一半 / 限制最长边）。每张图会立即按新参数重压，实时显示 原大小 → 压后大小 和压缩率。
  4. 缩略图点一下看原图大图。每张右侧「下载」只存这一张；底部「打包下载 ZIP」把当前所有压好的图打成一个包。
  5. 选 JPG 时可挑底色（白 / 黑）—— PNG 的透明区转 JPG 会按这个颜色铺底，避免变黑。
  6. 再点一次书签、按 Esc、点面板外面都能关；看大图时先按 Esc 关大图，再按一次关面板。

2口径与边界

情况处理
质量滑块只对 JPG / WebP 生效；PNG 是无损格式，质量参数不影响它，体积由像素内容决定
压缩后变大如实标红「大 N%」，不隐藏。小图或已是高压缩的图重编码后常会变大
透明图转 JPG按所选底色铺底再画，透明区不会变黑；PNG / WebP 原样保留透明
GIF / 动画 WebP只压首帧 —— 浏览器 canvas 经 <img> 会定格，本地无依赖无法保留动画
EXIF / 定位信息重编码会丢弃。对隐私是好事，但拍摄参数不会保留
超大图canvas 单边封顶 12000px，超限先等比缩小；编码失败保留原图并提示
几个要知道的坑

1. 不是所有图都能压小。已经压过的小图、纯色图、PNG 重编码后可能更大，工具会如实显示，你可以选择只下原格式那张。
2. 动画会丢。GIF / 动画 WebP 出来是静态首帧，需要保留动画请直接用专门的格式转换工具。
3. 批量图吃内存。一次选太多大图，浏览器 canvas 可能吃紧；建议一次 10 张以内，压完下掉再选下一批。
4. 改参数会重压所有已选图。选了很多张时每次拖动质量滑块都会触发一轮重编码，稍微等一下再看结果。
安全：纯前端，零后端、零上报。不调用任何网络接口，图片只在浏览器内存里经 canvas 处理，不上传、不写 localStorage。关掉面板数据就没了。下载的文件由浏览器直接存到本机。 整段代码约 26.4 KB。

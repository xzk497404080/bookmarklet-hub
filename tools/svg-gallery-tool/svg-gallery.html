SVG 图片探测器

在任意网页点一下书签，把当前页所有 SVG 抓出来排成画册。悬浮放大、单击直接下载，也可勾选批量导出；导出时自选 SVG / PNG / JPG。

SVG 图片探测器 ↑ 按住拖到书签栏

按住紫色按钮拖到浏览器书签栏松手。看不到书签栏按 ⌘⇧B（Windows Ctrl+Shift+B）。
代码约 ，全部可读，右键书签「编辑」能逐行看。

1怎么用

  1. 打开任意网页（不需要登录、不挑站点），点一下书签，画册盖上来。折叠内容可先展开，再点「重新扫描」。
  2. 默认全抓：可见隐藏微型 三类都在，空 默认过滤，勾「含空 SVG」可放出来。四类互斥，判定顺序 空 → 隐藏 → 微型 → 可见。
  3. 画册可以滚动：卡片宽度统一、高度按 SVG 自身宽高比走，条目再多也不会被压扁。悬浮卡片放大预览，单击卡片直接下载（按底部勾选的格式），点卡片左下角 ⤢ 进灯箱看大图、切背景、复制源码。按分类 / 来源 / 尺寸排序，搜索名称或 DOM 路径；重复图标多时勾「合并重复」。
  4. 响应式页面点「补抓响应式」：很多站点按断点条件渲染，另一套图标在桌面 DOM 里根本不存在（比如 app-shell__mobile-brand-icon 要窗口变窄才挂载）。工具会开一个 390px 宽的隐藏副本重新加载当前页，等页面渲染完把那套 SVG 一并收进画册，只跳过「图形和名字都完全相同」的条目 —— 不同断点的组件常共用同一份图形，名字不同就得保留，否则按名字搜不到。补进来的条目带「窄屏」角标，搜索框输「窄屏」可单独筛出。
  5. 底部选导出格式：SVG / PNG / JPG 可多选，倍数 1x / 2x / 4x，JPG 可挑底色。只有 1 个文件时直接下载、不打包；多个文件才出 ZIP，多选格式时按 svg/ png/ jpg/ 分目录。
  6. 下载选中只导出勾过的；一键全部保存导出当前列表全部条目（忽略勾选）。ZIP 里只放导出的图片文件，不再附带 manifest.json / index.html —— SVG 已自包含，单独打开就能用，不需要任何配套文件。
  7. 再点一次书签、按 Esc、点面板外面都能关。灯箱先按 Esc 关灯箱，再按一次关面板。
抓取全 DOM + 窄屏补抓内联、img、CSS 背景、data URI、object、响应式另一套
还原自包含化计算样式内联、补 xmlns / viewBox、展开 use、rem/em 固化成 px

2抓取范围与口径

来源处理方式
内联 <svg>主力。深拷贝后逐节点写回父页计算样式，脱离原页面 CSS 也能正确显示
Shadow DOM递归遍历所有 shadowRoot，这是最常漏的一类
<use href="#id">把被引用的 symbol / g 展开进 SVG，否则存下来是空壳
img / object / iframe同源 .svg 直接取源码；跨域取不到，见下方限制
CSS background-image扫描计算样式里的 url(...)，含 data:image/svg+xml 内联图
响应式断点 SVG桌面视口下没挂载的节点扫不到；点「补抓响应式」用 390px 隐藏副本补扫，按内容去重后并入画册
可见
正常占位渲染，且宽高都不小于 16px
隐藏
display:none / visibility:hidden / opacity:0 / 不占布局 / 位于 defs·symbol 内。图标 sprite 库全在这类
微型
可见但宽或高 < 16px。1×1 追踪像素归这里，不是丢掉
空
没有任何可绘制子元素，或包围盒宽高都是 0。默认过滤，可勾选放出
去重
按序列化内容做哈希，卡片角标显示 ×N。「合并重复」默认关，保证默认全抓
PNG / JPG
浏览器 canvas 渲染，尺寸按 SVG 标称宽高 × 倍数，单边封顶 8192px。JPG 先铺底色再画
几个要知道的坑

1. 跨域外链 .svg 拿不到源码。浏览器同源策略挡着，此时会导出一个 <image> 引用图（打开需联网），灯箱里能看到原 URL。同源的会直接取到源码。
2. 隐藏类导出后是「可见」的。故意不内联 display / visibility，否则 sprite 图标存下来还是一片空白。想复核它在页面上原本藏在哪，看卡片的「隐藏」角标和 reason。
3. use 图标颜色可能和页面不一致。展开 symbol 时颜色按 sprite 文档的计算值固定，若页面靠 <use fill="red"> 动态染色，导出的可能是 sprite 默认色。
4. CSS 动画、外链字体、SVG 内的外链 <image> 不会带走。导出的是静态快照；外部图片仍指向原 URL，离线打开会缺。
5. 有上限：最多 2000 个 SVG、12000 个节点/轮、40000 次样式计算。超了会自动降级（后续节点不再内联样式），界面会标注。
6. 只扫顶层 document 与 Shadow DOM，不递归页面里已有的 iframe。「补抓响应式」是另开一个窄屏副本，不是遍历现有 iframe。
7. 「补抓响应式」会重新加载一遍当前页（390px 隐藏 iframe，同源带 cookie），因此会多发一轮页面请求；站点设了 X-Frame-Options: DENY / CSP frame-ancestors 时会被拦，工具会提示降级。等待渲染最多 7 秒、整体 14 秒超时。
安全：纯前端，零后端、零上报。不调任何第三方服务；同源外链 SVG 由你自己的浏览器带着本机 cookie 取，cookie 不出本机。 抓到的数据只在内存里，关掉面板就没了，不写 localStorage。「补抓响应式」的隐藏副本加载的仍是当前这个同源地址，扫完即销毁。导出的文件由浏览器直接下载到本机。 整段代码约 81.0 KB。
